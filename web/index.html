The scene is about 9 MB and is downloaded once. It is untextured on purpose: every surface is a flat colour that says what the geometry is, not what it looks like in the game.

This browser has no WebGPU

The viewer needs it and there is no fallback to offer. Per-instance transforms and colours are read from a storage buffer, and WebGL2 has no storage buffers at all, so it is not a matter of a slower path — the renderer cannot be expressed.

Chrome, Edge, Safari 26 and later, and current Firefox all have it. On Linux Chrome you may need chrome://flags/#enable-unsafe-webgpu.

A desktop build with the same features, which uses Vulkan, Metal or D3D12 and reads the map straight out of your own CS2 install, is in the repository.
